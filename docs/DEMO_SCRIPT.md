# TrialLens: 3-minute live demo script

**Setup (before judges arrive):** `uv run uvicorn trialforge.api:app --port 8765`, open http://localhost:8765. The EMPOWER-Lung 3 review and its comparators are cached, so loading takes about 1 s. Keep the Evaluation tab pre-loaded in a second browser tab.

| Time | Screen | What to say |

| 0:00–0:20 | Title / Protocol review tab | "Clinical teams decide eligibility criteria largely from precedent and habit. Regeneron's own starter material says reviewers rarely get evidence-based feedback before the protocol is locked. TrialLens is a reviewer for one decision: does each eligibility restriction have evidence behind it? Every exclusion deserves evidence." |
| 0:20–0:40 | Load **NCT03409614** (EMPOWER-Lung 3, Regeneron). Point at the Chalk line under the regimen. | "This is a real, completed Regeneron phase 3. The Chalk-served registry profile shows the registry never mentions neutrophil counts. The lab thresholds exist only on page 67 of the 170-page protocol, and TrialLens read them from there. The regimen is cemiplimab, ipilimumab and platinum doublets, each traced to protocol pages." |
| 0:40–1:15 | Select **Hemoglobin ≥10 g/dL**. Scroll to the comparator table, then Evidence. | "TrialLens found four comparable trials automatically, all started before this one. Three used 9.0 g/dL. eNERGY used the same strict 10 g/dL, so the evidence is mixed, not one-sided. The protocol itself, on page 51, reports more grade 3–4 anemia with pemetrexed, which is a safety rationale. A toxicity rationale supports having *a* threshold, not this exact number, so this goes to review, not removal." |
| 1:15–1:30 | Purpose card + FDA guidance | "Restrictions exist for reasons: safety, tolerability, heterogeneity. TrialLens labels these as inferred and shows FDA's July 2026 lab-values guidance, quoted verbatim with section and line numbers." |
| 1:30–2:05 | Challenge form → *Load example input → "PD-1 is not myelosuppressive → relax ANC to 1.0"* → Verify | "Now I challenge it. This is a typed example, not a system finding. Relax the neutrophil threshold because cemiplimab isn't myelosuppressive. The premise is true, but the verifier **rejects** it: the other arms contain carboplatin, paclitaxel and pemetrexed. Each check says whether it is a factual check against a source or a clinical-logic rule. If I instead propose 9.0 g/dL for hemoglobin with a regimen-matched comparator, it is not approved. | 2:05–2:30 | **Review packet** tab → set a decision → Printable / PDF | "The output is a review packet for the protocol meeting: the requirement, its likely purpose, supporting and contradicting evidence, open questions and a next action, with a decision field that always allows *Needs medical review*. | 2:30–3:00 | **Evaluation** tab | "We measured it the way Regeneron's starter sheet suggests. We planted stricter thresholds into real, previously unseen protocols and checked whether TrialLens escalates them for review. Our extraction ran on unseen protocols, with first-run numbers kept. The verifier was also run on **Chalk Evaluations**. Limits we state openly: rule-based reasoning, single-annotator gold labels, no clinician validation yet. TrialLens doesn't decide; it makes the decision defensible." |

**If something fails live:** the Review packet and Evaluation tabs read saved results. Use `?nct=NCT02578680` (KEYNOTE-189) as a backup trial.

**Likely judge questions**
- *Isn't this just search?* The value is the comparison logic: regimen coverage, permissive comparator ≠ safe, toxicity ≠ threshold. Plus a verifier that rejects plausible-but-wrong reasoning and a measured planted-issue recall.
- *How does it differ from Regeneron/Keiji's ISPOR 2026 work?* Their published system drafts criteria from precedent. TrialLens reviews and challenges individual restrictions. They are complementary, and we don't claim their system lacks anything beyond what their abstract describes.
- *What does the AI do?* The evidence engine is deterministic. A model (via the Chalk Model Gateway) critiques and parses challenges, may only downgrade, and is always gated by the verifier.
- *Would you use this on internal protocols?* Yes, and the next step would be internal precedent: past amendments, internal lessons learned and the team's accept/reject history.
